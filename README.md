# J Fire

Clinical Research Financial Management Web App

J Fire is a web app that streamlines clinical trial financial management for small teams

⚙️ Usage

Enter a budget based on a clinical trial protocol, and see financial data and insight right away.

"Calculator" mode lets you enter nubmers manually, on the fly.

"Workbook" mode 

Track a project's finances, reporting, receivables and payables.

Manage a team across devices, locations and priviledges.

All is encrypted end to end, and personal data is always confidential.
